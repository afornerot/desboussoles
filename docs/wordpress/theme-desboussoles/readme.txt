== Description ==

Thème WordPress bloc (full site editing) inspiré de la structure de
Twenty Twenty-Five et habillé avec la charte graphique DesBoussoles :
police Poppins, palette vert / orange / jaune signature, contours noirs
dessinés à la main, coins arrondis, aplats sans ombre.

Un thème de blog et de pages classique, dont le look respecte la charte :

* Polices Poppins (400 / 400 italique / 800 / 800 italique) auto-hébergées
* Palette complète de la charte disponible dans les styles globaux
* Boutons pilule, cartes bordées, focus visible, contrastes accessibles
* Aucune ombre ni dégradé, conformément à l’ADN graphique du projet

== Installation ==

1. Copier le dossier `theme-desboussoles` dans `wp-content/themes/`
   (ou téléverser l’archive ZIP depuis Apparence > Thèmes > Ajouter).
2. Activer le thème « DesBoussoles ».
3. Configurer les menus dans Apparence > Éditeur > Navigation.
4. Créer une page d’accueil statique et l’assigner dans Réglages > Lecture.

== Frequently Asked Questions ==

= Comment utiliser les couleurs de la charte ? =

Elles sont dans l’éditeur de blocs : Couleurs > Palette (vert accord,
orange urgence, jaune signature, lilas, fonds de scène…).

= Comment obtenir les cartes et bandeaux de la charte ? =

Sélectionner un bloc Groupe, puis Styles de bloc > « Carte » ou « Bandeau ».
Le style « Carte » ajoute la bordure noire, les coins arrondis et le survol.
